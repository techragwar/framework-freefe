# About Ragwar Tech

Ragwar Tech is a software engineering portfolio focused on modern web
development, artificial intelligence, LLM applications, automation,
cloud infrastructure, APIs, and developer tooling.

The portfolio demonstrates practical engineering rather than only static
design work.

The frontend is intentionally built without a JavaScript framework.

The project uses semantic HTML, CSS, and modern JavaScript modules.

The backend uses Python and FastAPI.

The AI layer demonstrates LLM integration, retrieval augmented generation,
and LangChain-based application architecture.
