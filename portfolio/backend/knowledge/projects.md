# Portfolio Projects

## Framework-FreeFE

Framework-FreeFE is a portfolio application built without React, Vue,
Angular, or another frontend framework.

The frontend uses:

- HTML
- CSS
- Vanilla JavaScript
- ES modules
- responsive design
- browser APIs

The backend uses:

- Python
- FastAPI
- SQLAlchemy
- SQLite

The application includes:

- portfolio projects
- project case studies
- contact API
- AI assistant
- RAG knowledge base

## AI Research Assistant

An AI research assistant demonstrates how LLM applications can combine
language models with structured application logic and retrieval.

The system can be extended with document ingestion, embeddings,
vector databases, and agentic workflows.

## Agent Platform

The agent platform demonstrates an architecture for AI agents that can
reason about tasks, call tools, maintain state, and return structured
results.

The platform is designed to support future integrations with LangChain
and other AI orchestration systems.

## Developer Dashboard

The developer dashboard demonstrates a modern data-oriented application
with API integration, visualization, metrics, and operational views.

## Production API

The production API project demonstrates backend engineering,
configuration management, testing, deployment, observability, and CI/CD.
